# NOFX - AI多模型交易系统项目设计

## 项目概述

NOFX是一个基于AI的自动交易系统，支持多种AI模型(DeepSeek、Qwen、GLM等)和多个交易所(币安、Hyperliquid、Aster DEX等)的加密货币交易。系统采用Go后端 + React前端 + SQLite数据库的技术架构，提供完整的Web界面进行配置、监控和管理。

## 技术栈

- **后端**: Go 1.21+ + Gin框架
- **前端**: React 18 + TypeScript + Vite + TailwindCSS
- **数据库**: SQLite
- **AI集成**: DeepSeek API、Qwen API、GLM API
- **交易所**: Binance Futures、Hyperliquid DEX、Aster DEX
- **实时通信**: WebSocket
- **认证**: JWT
- **加密**: RSA加密存储API密钥

## 系统架构

系统采用分层架构设计，包含以下层次：

1. **前端层**: React Web界面，提供用户交互
2. **API层**: RESTful API服务器，处理HTTP请求
3. **核心业务层**: 交易逻辑、AI决策、风险管理
4. **数据访问层**: SQLite数据库、缓存、加密服务
5. **外部服务层**: 交易所API、AI模型API、行情数据源
6. **基础设施层**: 日志系统、通知、启动管理、监控

## 数据流

1. **配置流程**: 用户配置AI模型和交易所 → 创建交易员 → 启动自动交易
2. **交易流程**: 获取市场数据 → AI分析决策 → 风险检查 → 执行交易 → 记录结果
3. **监控流程**: 实时收集交易数据 → 更新界面 → 发送通知 → 记录日志
